# Сходимость общей компоненты по числу векторов

Этап 5 (`scripts/05_convergence.py`, `src/shared_refusal/convergence.py`). Запуск
`qwen2.5-3b_salad-o1o2o5o6`, 13.10.2026. Данные:
`results/qwen2.5-3b_salad-o1o2o5o6/convergence/convergence.json` на сервере.

## Вопрос

Общую компоненту мы получаем пересечением многих направлений отказа — DIM и RDO. Каждое
направление стоит денег (RDO — около 5 минут GPU на сид). Прикладной вопрос:

- сколько направлений нужно, чтобы компонента была **достаточно чистой**;
- с какого момента очередное направление уже **почти ничего не добавляет**.

Здесь и дальше «векторы» — объединённое множество DIM и RDO, различий между ними не делаем.
Пул — все 24 вектора запуска (4 DIM + 20 RDO).

## Что значит «чистая компонента»

Представим, что у нас бесконечно много направлений. Их пересечение дало бы компоненту w∞ —
то общее, что есть во всех направлениях отказа этой модели. Компонента w_N из N векторов —
её приближение. Чистота — насколько w_N совпадает с w∞:

    ρ_N² = cos²(w_N, w∞)

ρ² = 1 — компонента совпала с идеальной; ρ² = 0.5 — половина «энергии» w_N лежит не там.

Проблема в том, что w∞ у нас нет: есть только 24 вектора.

## Почему не подходят очевидные метрики

**Норма компоненты.** Компонента — собственный вектор, он всегда единичный, его норма от N
не зависит. Идея «насколько уменьшилась норма» имеет смысл для *среднего* N векторов: шум
усредняется, и норма среднего падает к доле общей части. Ровно это показывает λ1(N) —
доля общей энергии внутри подмножества (см. ниже). Это полезная метрика, но она говорит,
сколько общего внутри подмножества, а не насколько w_N близка к w∞.

**Сходство с компонентой всех 24 векторов, cos²(w_N, w_24).** Интуитивно, но по кругу:
w_24 построена из тех же векторов, что и w_N. При N = 20 любые два подмножества из 24
почти совпадают по составу, и сходство высокое просто из-за общих векторов, а не потому,
что компонента стала чистой. Эта метрика систематически завышает сходимость — сильнее
всего там, где ответ важнее всего (большие N).

## Метод: непересекающиеся половины (split-half)

Идея — сравнивать между собой две компоненты, построенные на **разных** векторах, вместо
того чтобы сравнивать с w∞, которой у нас нет.

1. Берём из пула два подмножества A и B по N векторов **без общих элементов**.
2. Строим по каждому компоненту: w_A и w_B.
3. Считаем, насколько они совпадают: r = |cos(w_A, w_B)|.
4. Повторяем для многих случайных пар (A, B) и усредняем.

**Почему r — это ρ².** Каждая из компонент — это w∞ плюс своя ошибка:

    w_A = ρ_A · w∞ + (ошибка A),   w_B = ρ_B · w∞ + (ошибка B)

A и B не имеют общих векторов, поэтому их ошибки независимы. В пространстве размерности
2048 две независимые случайные ошибки почти ортогональны друг другу и w∞. Тогда в скалярном
произведении выживает только общая часть:

    cos(w_A, w_B) ≈ ρ_A · ρ_B = ρ_N²        (A и B одного размера N)

Пример: если каждая половина «на 90 % чистая», cos(w_A, w_B) ≈ 0.9 · 0.9 = 0.81. Мы
измеряем 0.81 и получаем ρ_N² = 0.81, ρ_N = 0.9 — не зная w∞.

Модуль нужен потому, что знак собственного вектора произволен: w и −w — одна компонента.

**Допущения.**
- Ошибки разных векторов независимы. Если у всех направлений есть общее систематическое
  смещение, оно войдёт и в w_A, и в w_B, и метод примет его за часть w∞. Значит, w∞ здесь —
  предел *этого способа* получать направления (DIM + RDO на этой модели и этих данных), а
  не «истинное» направление отказа в каком-то абсолютном смысле.
- Пространство высокой размерности (у нас 2048), иначе ошибки не ортогональны.

**Проверка на синтетике** (`tests/test_convergence.py`). Строим векторы с известной общей
частью и шумом, где w∞ известна. Оценка split-half совпадает с настоящим cos²(w_N, w∞) в
пределах 0.03, а подогнанное k совпадает с заложенным.

**Ограничение.** Две непересекающиеся половины по N требуют 2N разных векторов, поэтому
при пуле 24 метод работает только до **N = 12**.

## Модель «общая часть плюс шум»

Если каждый вектор = общая часть + свой независимый шум, то при пересечении N векторов шум
гасится как 1/N. Для единичных векторов v_i = c·w∞ + √(1 − c²)·n_i это даёт

    ρ_N² = 1 / (1 + k/N),   то есть   1/ρ_N² − 1 = k/N,   k = (1 − c²)/c²

При N = 1 формула даёт ρ² = c² (один вектор совпадает с w∞ ровно настолько, насколько в
нём есть общей части), при больших N — 1 − ρ² ≈ k/N.

Подгоняем k по точкам split-half N = 1 … 12. Второй вариант — с плато,
1/ρ² − 1 = k/N + b: если b > 0, у компоненты есть часть, которую добавление векторов не
убирает, и ρ² не дойдёт до 1. Модель позволяет посчитать:

- сколько векторов нужно для заданной чистоты: N = k / (1/ρ² − 1 − b);
- сколько добавляет очередной вектор: ρ²(N+1) − ρ²(N).

## Дополнительные метрики

**Сдвиг от ещё одного вектора**, 1 − cos²(w_N, w_{N+1}). Берём случайный порядок всех 24
векторов, строим компоненту по первым 1, 2, …, 24 и смотрим, насколько она меняется от
каждого следующего. 1000 случайных порядков. Непересекающиеся половины не нужны, поэтому
метрика доступна **до N = 23**. Она прямо отвечает на вопрос «стоит ли учить ещё», но не
говорит, *куда* сходится компонента: при общем систематическом смещении сдвиг падал бы
точно так же.

**cos²(w_N, w_24)** и **λ1(N)** — для сравнения, с оговорками выше.

## Выборка

- N = 1 … 20, не больше 1000 комбинаций на N; где различных комбинаций меньше — берутся
  все (при N = 1 для split-half — все 276 пар).
- Сид генератора — 21.
- Пул не фильтруется: в нём и 4 почти одинаковых DIM, и три выбивающихся RDO-сида.

- Практические пороги: если «уже не стоит учить» — это сдвиг меньше 1 %, он достигается на

## Вывод

На этой модели и этих данных компонента сходится как усреднение независимого шума:
1 − ρ² ≈ 1.7/N. Для ρ² ≈ 0.9 достаточно около 16 направлений, наши 24 дают ≈ 0.93. Каждое
следующее направление добавляет всё меньше (≈ 1.7/N² к ρ²), и признаков предела, который
нельзя преодолеть добавлением векторов, нет — по крайней мере до N = 12 напрямую и до 23
по сдвигу.

## Что дальше

- **Неравные половины (CPU, на тех же данных).** A из N векторов и B из оставшихся 24 − N
  не пересекаются, поэтому |cos(w_A, w_B)| ≈ ρ_N · ρ_{24−N}, а ρ_{24−N} уже измерен при
  24 − N ≤ 12. Это даёт прямое измерение ρ_N до N = 23 без модели; на правом краю шумно.
- **Больше векторов (GPU).** Обучить ещё RDO-сидов: с пулом 64 split-half доходит до 32, и
  оценка «33 вектора для ρ² = 0.95» станет измерением, а не экстраполяцией.
- **Разбор по составу.** В `convergence.json` для каждой комбинации записано число DIM в
  ней: можно проверить, сколько разброса даёт доля DIM (они почти совпадают между собой).
- **Не делать бутстрэп с возвращением:** один вектор попадёт в обе половины, и совпадение
  будет искусственно завышено — та же круговость, что у cos²(w_N, w_24).
